# Bloom Catcher

Mini game HTML tunggal yang dapat dimainkan langsung di browser.

## Cara Menjalankan
1. Jalankan server statis sederhana, misalnya:
   ```bash
   python -m http.server 8000
   ```
2. Buka `http://localhost:8000/index.html` di browser favorit Anda.
3. Tap kelopak bunga yang muncul untuk mengumpulkan skor.
